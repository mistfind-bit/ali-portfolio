# 阿梨｜AI 協作應用與互動作品集

這是一個用來整理與展示個人實作的靜態作品集網站。

## 定位
從生活需求、學習工具到互動遊戲，把想法做成可以真的操作的原型。

我負責需求定義、功能與玩法設計、素材方向、實際測試、問題回報與反覆迭代；以 AI 協作進行程式實作、除錯、技術研究與部分視覺素材製作。
